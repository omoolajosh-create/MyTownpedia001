# MyTownpedia

Welcome to MyTownpedia — a community-driven platform dedicated to preserving the history, culture, and stories of towns across Nigeria and beyond.

## 🌍 About
MyTownpedia allows users to:
- Explore town histories  
- Share stories and experiences  
- Upload images and media  
- Contribute to community knowledge  

## 🚀 Features
- Public submissions  
- Admin approval system  
- Town profile pages  
- Search and discovery  

## 🛠 Built With
- React + Vite  
- Tailwind CSS  
- Supabase  
- Vercel  

## 📌 Status
This project is actively being developed and improved.
